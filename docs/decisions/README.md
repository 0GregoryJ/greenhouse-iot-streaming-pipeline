# Architecture Decision Records

This folder will hold Architecture Decision Records (ADRs): short documents that capture a significant architectural decision, the reasoning behind it, and its consequences. No ADRs have been written yet. They will be added as decisions are formally documented.

For how the system works today, see [Architecture](../architecture.md).

## Format

Each ADR is one Markdown file with these sections:

| Section | Content |
| --- | --- |
| **Context** | The problem, constraints, and alternatives considered |
| **Decision** | What was decided, stated plainly |
| **Consequences** | Resulting trade-offs, benefits, risks, and follow-up work |
| **Status** | `Proposed`, `Accepted`, `Superseded by <ADR>`, or `Deprecated` |

Superseded ADRs stay in the folder, marked as superseded, so the history of decisions is preserved.
